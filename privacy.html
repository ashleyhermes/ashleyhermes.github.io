隱私權說明

版本日期：2026-10-28 · 自本版本公開發布時起適用

本說明適用於 Ashley Workspace 的個人授權工作功能，以及本應用程式說明網站。應用程式不提供公眾註冊。

1. 存取的 Google 資料

依 Google 同意畫面核准的權限及使用者指定的任務，資料可能包括：

  • Gmail：郵件內容、主旨、寄件人與收件人、標籤、附件及相關中繼資料；權限包含讀取、修改及寄送。
  • Calendar：行事曆與活動資訊，可依授權讀取及管理活動。
  • Contacts：聯絡人及聯絡方式，僅讀取。
  • Drive：檔案內容、名稱、權限及中繼資料；目前要求的存取範圍不限於應用程式自行建立的檔案。
  • Docs 與 Sheets：指定文件與試算表內容，可依授權讀取或編輯。

取得 API 權限不代表應用程式會主動讀取所有資料；實際操作仍須符合使用者指示、已批准的排程及操作限制。

2. 用途與操作授權

Google 資料用於使用者授權的郵件搜尋、整理、擬稿與寄送、行程管理、收件人查找，以及指定檔案、文件與試算表的處理。寄信、分享、刪除等具影響的操作，須有相應的個別授權或已批准排程。OAuth 授權不等於對任意操作的無條件許可。

3. AI 處理、資料傳送與第三方

任務可能由本地模型或外部模型服務處理。目前啟用的外部模型服務包括 OpenAI，透過 ChatGPT 帳戶登入的 Codex 服務使用。任務所需的 Google 資料片段可能進入模型輸入、工具回傳及對話脈絡，並傳送給 OpenAI；不宣稱所有處理均在本機完成。資料可能在使用者所在國家或地區以外處理。

帳戶管理者已確認關閉 ChatGPT「為所有人改善模型」設定。本應用程式不得將 Google 使用者資料出售、用於廣告定向，或用於開發、改善或訓練非個人化的通用 AI／ML 模型。關閉模型訓練不等於第三方不保存任何資料；供應商處理、安全及保存安排仍依適用服務條款、隱私政策和帳戶設定。

使用者若透過 Telegram 與應用程式互動，該平台會處理傳送的訊息、附件及回覆；包含 Google 資料的回覆亦可能經過該平台。其他收件人、共享目的地或外部工具僅應在完成使用者已授權功能所需的範圍內取得資料。新增外部服務或擴大用途前，應更新說明並取得適用同意。

供應商政策：OpenAI 隱私政策、Telegram 隱私政策。

4. 保存、安全及刪除

Google OAuth 憑證由執行環境保存，不放入本公開網站或公開程式碼庫。使用者授權取得的內容與衍生資料可能保存在管理者控制的本機執行環境，包括工作檔、對話資料庫、執行紀錄及備份。

本應用程式目前沒有涵蓋上述所有資料的統一自動刪除期限；相關紀錄可能持續保存，直到管理者另行清理。工作檔、對話、執行紀錄與備份需分別處理，刪除其中一份不代表其他副本已刪除。本應用程式不承諾零保存、立即清除所有備份或所有儲存位置皆已加密。

使用者可透過下方支援信箱提出資料範圍查詢或刪除要求。管理者應確認請求與身分，處理其控制範圍內的相關資料；供應商持有的資料則依其設定、刪除機制與適用政策處理。本頁不承諾未經確認的完成期限。

5. 撤銷存取權

可於 Google 帳戶的第三方連線設定撤銷 Ashley Workspace 的存取權，並停止相關工作或排程。撤銷不會自動刪除先前保存的工作檔、對話、紀錄或備份；資料刪除需另行處理。

6. 本靜態網站

本網站以 GitHub Pages 代管，只提供應用程式與政策說明，不是 Google 登入入口，沒有表單、分析程式、第三方嵌入或自行加入的追蹤器。網站檔案不包含 Google 郵件、文件或授權憑證。GitHub 可能依其政策處理訪客 IP 等基本連線資訊；詳見 GitHub 隱私聲明。

7. Limited Use、更新及聯絡

Ashley Workspace 對從 Google API 取得的資訊之使用，以及向其他應用程式傳送該資訊，須遵守 Google API Services User Data Policy，包括適用的 Limited Use 要求。本頁不是 Google 驗證通過或第三方合規稽核證明。

資料用途或處理方式有重大變更時，應先更新說明並取得適用同意。支援與資料請求：ashleyaiagent@gmail.com。
